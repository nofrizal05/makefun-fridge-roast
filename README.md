A smart fridge, in its own voice, roasting the household it serves: it beeps the moment you leave its door open ten seconds, yet it has quietly guarded last March's leftovers for eight months like they pay rent. One line, 130 characters, deterministic — the same roast every run.

## Run it

```sh
python3 main.py
```

The program writes the roast to `/output/entry.txt` and prints the same line to stdout. Python 3.13 standard library only; no third-party packages, no network, no secrets.
